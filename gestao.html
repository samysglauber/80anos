Como Conectar com uma Planilha no Google Drive

Para que as confirmações dos convidados no GitHub Pages vão direto para uma planilha em tempo real, siga estes 3 passos (leva 2 minutos):

  1. Crie uma nova planilha no seu Google Drive.
  2. Vá no menu Extensões > Apps Script e cole o código abaixo:
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([new Date(), data.name, data.status, data.count, data.message]); return ContentService.createTextOutput("OK"); } function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var rows = sheet.getDataRange().getValues(); return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON); }
  1. Clique em Implantar > Nova Implantação > Tipo: Web App, defina o acesso como "Qualquer pessoa" (Anyone) e copie o URL gerado no campo googleSheetWebhookUrl do seu config.js!
